# C-Sum-Of-N-Numbers

This contains programs for sum of 2 numbers to N numbers 

Note:- 
1) Time Complexity ~ T 
2) Space Complexity ~ S 

# Sum_Of_2_Numbers.c
T ~ O(1) 
S ~ O(1) 

First file in the repository. Just adds 2 'double' data type numbers 

# Sum_Of_3_Numbers.c
T ~ O(1) 
S ~ O(1) 

Just adds 3 'double' data type numbers 

# Sum_Of_N_Numbers_Array.c
T ~ O(n) 
S ~ O(n) 

This algorithm firstly saves all the numbers to an array, then sums the. 
It can be modified and used when we need to know the sum as well as the inputs 

# Sum_Of_N_Numbers_Inplace.c
T ~ O(n) 
S ~ O(1) 

This algorithm takes a number and immediately adds it the sum. 
It is faster and uses less space and can be used when we need to just know the sum
